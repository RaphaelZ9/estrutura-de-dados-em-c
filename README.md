# 💻 Estrutura de Dados em C

Projeto acadêmico desenvolvido durante a graduação em **Ciência da Computação**, com foco na implementação e prática de conceitos fundamentais de **estruturas de dados utilizando a linguagem C**.

## 🎯 Objetivo

Aplicar conceitos de estruturas de dados e programação em C por meio de implementações e exercícios práticos.

O projeto demonstra conhecimentos fundamentais de:

* Estruturas de dados
* Programação em C
* Organização e manipulação de dados
* Lógica de programação
* Implementação de algoritmos

## 🛠️ Tecnologia

* **C**

## 📚 Contexto

Projeto desenvolvido durante a graduação em **Ciência da Computação** como parte dos estudos relacionados a estruturas de dados e programação.

O código disponível neste repositório representa os exercícios e implementações desenvolvidos durante o período acadêmico.
